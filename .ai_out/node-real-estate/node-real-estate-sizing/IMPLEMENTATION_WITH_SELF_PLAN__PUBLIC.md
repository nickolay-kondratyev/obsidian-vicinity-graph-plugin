# IMPLEMENTATION_WITH_SELF_PLAN — PUBLIC

Width-only node real-estate iteration. Snug capped width with wrap-to-2-lines;
folder-prefix breadcrumb removed entirely. Height untouched.

## What changed
- **Width formula** (`nodeDimensionsPx`, `src/view/graphIdentity.ts`):
  `width = max(node.sizePx, min(NODE_MAX_LABEL_WIDTH_PX, snugSingleLine))`, `height = node.sizePx` (unchanged).
  When a title's snug single-line estimate exceeds the cap, width pins to the cap and the title
  wraps onto the 2 lines CSS already allows (`-webkit-line-clamp: 2`).
- **Breadcrumb removed** end-to-end: render (`NoteNode.tsx`), CSS rule (`graph-view.css`
  `.vicinity-graph-node__breadcrumb`), reserved width, `FlowNodeData.breadcrumbFolder`,
  threading through `flowMapping.ts` / `elkMapping.ts`, and `breadcrumbFolderOf` (+ its tests) deleted.
  No dead params / no `@Deprecated`.

- `NODE_LABEL_HORIZONTAL_PADDING_PX`: 20 (unchanged).
