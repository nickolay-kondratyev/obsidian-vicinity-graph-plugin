# IMPLEMENTATION_WITH_SELF_PLAN — PRIVATE state (Global Node Exclusion)

Branch: `global-node-exclusion`. Rehydrate from this file.

## Binding decisions (from CLARIFICATION)
- GLOBAL enable + global pattern list. New `PluginData.nodeExclusion { enabled, patterns[] }`, default `{false, []}`, defensive parse, version stays 1.
- Roots exempt (main + pinned), even if they match. Only neighbor discovery excludes.
- Case-sensitive `new RegExp(pattern)`, tested UNANCHORED `regex.test(vaultPath)` against full vault-relative path incl. extension. Invalid regex silently skipped.
- Excluded iff ANY enabled+valid pattern matches. Disabled/empty ⇒ no-op.
- Applied at BFS neighbor discovery in VicinityTraversal. Exclusion checked BEFORE isNodeBearing (perf: skip metadata + expansion), root-exempt.
- Count = distinct vault paths rejected by exclusion during traversal → VicinityGraph.excludedNodeCount → ControlsModel.excludedNodeCount → toolbar pill. Shown only when enabled AND count>0.

## Design
- `NodeExclusionSettings { enabled, patterns }` lives in `engine/types.ts` (consistent w/ DepthSettings/ViewSettings). `excludedNodeCount` added to VicinityGraph.
- Engine consumes `GraphBuildRequest.nodeExclusion?: NodeExclusionSettings` whole (like globalView). Engine gates on `enabled` and builds matcher from patterns.
- New pure class `engine/PathExclusionMatcher.ts`: `fromPatterns(patterns)` (skips invalid), `excludes(path)`. Empty ⇒ none-matcher.
- Traversal: constructor gains matcher; traverse computes rootPaths up front, threads to bfs; bfs skips+counts excluded non-root neighbors via shared Set in TraversalCollector. TraversalResult gains `excludedNodeCount`.
- Adapter: GraphRequestInputs.nodeExclusion (from PluginDataStore.nodeExclusion()); assembler passes it to request; builder passes graph.excludedNodeCount to ControlsModelBuilder.build(inputs, count).
- ControlsModel gains `nodeExclusion: NodeExclusionSettings` (write ctx) + `excludedNodeCount: number`.
- settingsWritePlan: interaction `global-node-exclusion` {nodeExclusion}; command `node-exclusion` {nodeExclusion}; ctx gains nodeExclusion.
- ControlsActions: node-exclusion → pluginDataStore.saveNodeExclusion.
- PluginDataStore: nodeExclusion() / saveNodeExclusion().
- View: NodeExclusionSection.tsx pill in GraphToolbar; settings tab section (toggle + textarea). CSS pill in graph-view.css.
