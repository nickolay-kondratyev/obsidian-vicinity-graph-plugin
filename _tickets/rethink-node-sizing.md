Rethink node sizing.

Node sizing should be allowed to be set based on the outline that is available for the node not just the amount of size the node takes and then fitting it with outline, we should have a a smoother way to be able to deal with informational nodes that are outline based, which would allow the user to choose the nodes sizing basedd on the outline that are present for the node.

I am envisioning a rethink on node sizing control to bring forward pill like choise in the overall strategy that is used to decide the size of the node. One of them would be to fit it to outline the other one would be to enable the size based controls off of levers that we currently have that is -> [we optionally taking into account the link count, the size of the note].
