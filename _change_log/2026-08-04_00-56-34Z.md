Third adversarial review of the docid-keyed per-node override work (36354cd + 84e983c + b0f793b). Two rounds already landed; this pass found one behavioral issue and two stale docs.

1. **A non-finite pixel box is now REFUSED, not degraded to 24px.** `clampNodeSizeOverridePx` degraded `NaN` to `NODE_OVERRIDE_HARD_MIN_PX`, so a future drag-resize that ever reported an unmeasurable box would have silently PERSISTED a 24x24 dot the user never asked for — and made that bug indistinguishable from a deliberate tiny node. It also disagreed with the load path, which drops an unusable `sizePx` outright, and with the repo's own `clampSizingNumber` rule (`NaN` -> the field's spec DEFAULT — an override has no default, ABSENCE is what "no override" means). The clamp now returns `NodeSizeOverridePx | undefined`; `PluginDataStore.saveNodeOverrideField` stores NOTHING for a refused box (no `data.json` write, the previously stored box survives), and `parseNodeSizeOverride` stopped re-testing finiteness so the two paths ask ONE rule. Three tests added.
2. **`docs-internal/architecture-map.md` was stale** — the file CLAUDE.md calls "orient here first" still said `data.json` holds "global settings + the pinned set" and that `OrphanSweeper` "prunes stale pins". CLAUDE.md and `high-level-plan.md` were updated by the earlier rounds; this one was missed.
3. **`SettingsRootSnapshot`'s contract comment was stale** — "`PluginData` minus `version`/`pins`" now also excludes `nodeOverrides`. It is the definition a future settings slice would be added against.

NOT fixed, reported as an observation: a foreign docid of literally `__proto__` passes `DocPersistEligibility.isFilenameSafeDocId`, and `nodeOverrides` is the codebase's first docid-keyed OBJECT map — `map[docid] = entry` would mutate the prototype instead of adding a key, silently losing that one doc's override. Closing it cleanly means renaming `isFilenameSafeDocId` (its behavior must match its name) and rippling through callers/tests, which is out of proportion to a case no generated id (`docid_{24 base36}_e`) can reach.

Verified: `npm run check` clean, `npm test` 1512 passed. Pure engine/persistence change — no view surface touched, so `npm test` is the gate per CLAUDE.md.
