New `src/view/GraphViewOpener.ts` owns placement: `right-sidebar` (getRightLeaf) vs `main-area` (getLeaf('split','horizontal') = core "Split down"). Running a placement command while the graph sits elsewhere detaches and re-creates it there (human-aligned: move, not duplicate); running it for the current region only reveals (no rebuild).

Commands: `open-vicinity-graph` (id unchanged, renamed to "Open vicinity graph in right sidebar") and new `open-vicinity-graph-below`. `main.ts.activateView()` removed.

Coverage: `e2e/graphPlacement.e2e.ts` (harness gained `executeCommand` + `graphViewPlacements`); NOT executed locally — no Obsidian binary in this environment (OBSIDIAN_PATH unset).
