`renderExclusion()` in `src/view/VicinityGraphSettingTab.ts` now returns early before rendering the 'Exclusion patterns' textarea when `nodeExclusion.enabled` is false. Toggling the enable switch re-renders the tab (`this.display()`) so the textarea appears/disappears immediately. Patterns remain in the store untouched — only the `enabled` flag changes — so re-enabling restores the previously entered patterns.
