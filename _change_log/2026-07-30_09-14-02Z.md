Closes ticket nid_9uzrvqv0k5qgckgdaqtgr41ky_e (follow-up to nid_hatwq2jlkhno5t6awcz0q6t9q_e, which converted every OTHER typed panel field).

- `SizingMetricRow`'s weight input was controlled + writing per keystroke. It now shares the full uncontrolled/blur-commit protocol via a new `useNumberFieldCommit` hook in `src/view/SettingsRowView.tsx` — bounds, defaultValue, reseed key, Enter-blurs-to-commit and the aria refusal wiring — while keeping its own markup. `NumberField` folded into `NumberRow`.
- Refusal state is now bound to the stored value it judged (`NumberFieldRefusal`, `src/view/numberRowCommit.ts`), so a stale refusal message + aria-invalid can no longer outlive a store move.
- New source-scan tripwire `src/view/typedNumberFields.test.ts` over every row-rendering module: a panel number input may not be controlled. Shared scan reader extracted to `src/view/rowRenderingSource.ts`.
- `e2e/controlsRestart.e2e.ts` helper now blurs after setting a number input — without it the spec would have stored nothing.
