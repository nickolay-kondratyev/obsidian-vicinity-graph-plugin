Created `src/engine/SettingsSpec.ts` (`SETTINGS_SPEC`): one nested structure mirroring the `PluginData` type shape (globalDepths / globalView -> sizing.metrics, forceLayout / nodeExclusion). Numeric slider/stepper fields carry {default,min,max,step}; nodeCap {default,min}; booleans/enums {default}. JSDoc WHY rationales moved onto the leaves; inline `groupByFolder: true` folded in.

`EngineDefaults.*`, the `DEFAULT_*` constants, `FORCE_LAYOUT_RANGES`, `MIN_NODE_CAP`, and stepper bounds are now thin projections of the spec (no duplicated literals). Added `SettingsDefaults` navigation shim pointing at the spec. Engine purity preserved (spec imports only ./types).

Pure refactor: zero value changes (reviewer cross-checked every leaf byte-identical). Review MINOR fixed: sizingSettings() defensively spread-copies metric leaves. Tests: 740 passing, tsc strict clean.
