Closes ticket nid_xwfw86nqr8af7eygqod8lh5cp_e.

`e2e/edgeRouting.e2e.ts` and `e2e/edgeRoutingEval.e2e.ts` each carried a byte-identical `setAllEdgesVisibility` free function that reached into `app.plugins.plugins[PLUGIN_ID].pluginDataStore` and re-saved the global view. That duplicated KNOWLEDGE of the persisted global-view schema across two files.

Now: `ObsidianHarness.setEdgeVisibility(mode: EdgeVisibilityMode)` in `e2e/obsidianHarness.ts`, a sibling of the existing `setGlobalNodeCap` / `setMaxNodeSizePx` / `setNodePreviewPreference` family. Typed against the real union via a type-only import from the `src/engine` barrel instead of a bare string literal. A separate `e2e/pluginSettings.ts` was rejected — it would have split one cohesive runtime concern.

Pure refactor: no assertion, ordering, or timing change. The method deliberately omits `refreshOpenViews()` to stay behavior-identical to the old helpers; that is stated as a precondition in its JSDoc.

Gates run independently by implementer and reviewer: `npm run check` green, `npm test` 990/990, `npm run test:e2e -- edgeRouting.e2e.ts edgeRoutingEval.e2e.ts` 7/7 against a real Obsidian.

Deferred into nid_g4iae40tww9abtwrexdrvic0y_e: ~14 remaining inline `pluginDataStore` sites across the three settings specs, plus `setNodePreviewPreference` hand-repeating its literal union.
