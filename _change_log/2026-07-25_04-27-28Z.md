## What changed

Adds `ViewSettings.nodePreviewPreference` (`auto` | `outline` | `image`, default
`auto`), surfaced as a segmented **Preview** pill in BOTH the settings tab
("Node contents" card) and the in-graph controls panel ("Node contents"
disclosure). Global scope — both surfaces edit the same value.

## The architectural part

Previously `ObsidianLinkProvider.outlineOf()` returned `[]` to *mean* "the image
won", destroying the heading data before it left the adapter. With `auto` now
only one of three branches, that no longer works.

The adapter became a **fact reporter**: it always extracts the real outline and
reports `imagePrecedesOutline` through `FileMetadata` -> `TraversedNode` ->
`GraphNode`. The precedence rule collapsed into exactly one pure function,
`nodePreviewKind({preference, outlineEntryCount, hasImage, imagePrecedesOutline})`,
called from `flowMapping.toFlowNodeData`, so `FlowNodeData` carries the decided
`preview` and `NoteNode` decides nothing. The whole feature is therefore
unit-testable without React component tests.

## Invariants deliberately preserved

- **`auto` is behaviour-identical to the previous rule** — verified across all 10
  reachable note shapes, including the frontmatter-image sentinel and the
  unresolvable `![[missing.png]]` case that must NOT suppress the outline.
- **A preference never empties a node** — it falls back rather than blanking.
- **`sizePx` stays preference-independent**, so toggling is a data-only refresh
  with no relayout (`GraphStructureDiff.decideLayout` is insensitive to it).
- **"Fits" remains the existing 104px container-query gate** — no JS measurement
  was invented.
- `PERSISTED_SHAPE_VERSION` stays 2 (additive field with a spec default), so no
  user's stored globals are discarded.
- Settings section count stays 6 (the row joined the existing card).

## Docs

README, `high-level-plan.md`, `architecture-map.md` and the superseded
"no enable/disable toggle by design (CLARIFICATION Q2)" comments were reconciled
as **superseded, not contradicted**: document position still decides, under `auto`.

## Human decisions

1. 3-way pill (not 2-way), so nothing previously supported was removed.
2. Default `auto`, so upgrades look identical until opt-in.
3. Global scope only, no per-doc override.
4. Unselected trough uses `--background-modifier-form-field` so the pill reads as
   a real inset input.
