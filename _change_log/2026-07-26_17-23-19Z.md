The three settings specs (`settingsResetReview`, `settingsResetVerify`, `settingsUxVisual`) each carried a drifted copy of `openSettingsTab` / `card` / `resetButton` / `confirmDialog` / `readGlobals`, and inlined the persisted global-view schema ~14 times as `app.plugins.plugins[PLUGIN_ID].pluginDataStore`.

**What changed**

- New `e2e/settingsTabPage.ts` page object (`open` / `close` / `redisplay` / `card` / `resetButton` / `resetAllRow` / `resetAllButton` / `confirmDialog` / `dialogButton` / `openModals`), consumed by all three specs. It imports no `fs`, so the `vaultTarget.test.ts` source scan has nothing to object to and each spec keeps its own literal `OUT_DIR`.
- `ObsidianHarness` is now the ONLY holder of `pluginDataStore` knowledge, via `readGlobals` / `saveGlobalView` / `saveGlobalDepths` / `saveNodeExclusion` / `refreshOpenViews` / `reloadPlugin`; the pre-existing typed setters compose those primitives. Snapshot types are type-only imports of the engine`s real `ViewSettings` / `DepthSettings` / `NodeExclusionSettings` / `NodePreviewPreference` — the last of which also removes the hand-repeated `"auto" | "outline" | "image"` union, matching the `EdgeVisibilityMode` precedent.
- Exactly one `setTheme` survives: the harness body-class toggle. `settingsResetVerify`s local `setTheme("moonstone" | "obsidian")` and its `waitForTimeout(200)` are deleted.

**WHY the harness body-class setTheme won.** Neither theme-touching test asserts anything about the theme — they assert footer copy and take screenshots, so no computed-style assertion could go vacuous. The lever is independently proven to restyle by `vicinityGraph.e2e.ts`, which drives `harness.setTheme` and asserts arrowhead fill equals the theme`s resolved `var(--text-faint)`. The deleted variant`s only unique effect was persisting the theme id into the vault appearance config — nothing reads it, and under `VICINITY_E2E_VAULT` that is a real-vault mutation. Dropping the 200ms sleep is safe: a class toggle is synchronous.

**Behavior preservation.** Pure refactor. No test reordered, renamed, deleted, merged, or weakened; test titles and order are byte-identical per spec. The serial-mode state chains were specifically preserved — `settingsUxVisual`s row-name test still re-enables exclusion itself, and the Preview-pill pair still consumes the `"image"` write left by its predecessor. `seedPreviewPreference` keeps its settings-tab `redisplay()` rather than collapsing into the harness `refreshOpenViews()`.

**Gates:** `npm run test:e2e` 79 passed / 1 skipped / exit 0 both BEFORE (baseline on the clean tree) and after; `npm test` 990 passed; `npm run check` clean.
