Removes the native page preview on node hover (ticket `nid_jnw75pg24q4itujs8vfgqj4mh_e`),
reverting the interaction added in step-05 and re-scoped in `2026-07-23_17-13-40Z`.
The node itself carries the note's outline or thumbnail, so a popover on hover
only obscured the graph the human is reading.

- **`NoteNode`**: the `onMouseEnter` trigger is gone. Its wrapper div STAYS — it
  is load-bearing layout (it flex-grows so the attachment strip sits on the
  node's bottom edge, replacing the strip's old `margin-top: auto`) — and is
  renamed `.vicinity-graph-node__preview-zone` → `.vicinity-graph-node__content`,
  since the old name named a preview that no longer exists.
- **Ports**: `HoverPreviewRequest` and `GraphUiPort.showHoverPreview` deleted;
  `ObsidianGraphUi` no longer implements `HoverParent` and no longer takes a
  hover-source id.
- **`main.ts`**: `registerHoverLinkSource(...)` dropped, so the graph is no
  longer listed as a source in the Page-preview core-plugin settings.
- **e2e**: the old hover-dead-zone selector test now guards the layout invariant
  that kept the wrapper alive — it measures that the attachment strip's bottom
  lands on the node's inner bottom edge, so deleting the wrapper's `flex-grow`
  (which now looks purposeless) fails loudly instead of silently unpinning the
  strip. Pure view-layer change — no engine changes.
