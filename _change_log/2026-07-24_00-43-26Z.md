## What changed
- **Engine**: removed `LayoutMode` type, `LAYOUT_MODES`, `DEFAULT_LAYOUT_MODE`, and the `layoutMode` field from `ViewSettings`/`ViewSettingsOverride` and the resolver.
- **View**: deleted `LayoutSection.tsx` (toolbar layout `<select>`) and its `GraphToolbar` usage; removed the `global-layout` settings command; deleted elk `ELK_LAYERED_ROOT_OPTIONS`, `ELK_RADIAL_ROOT_OPTIONS`, `ELK_ROOT_OPTIONS_BY_MODE`, `ELK_LAYER_SPACING`; collapsed `elkMapping.ts` mode-branching (always `ELK_GROUP_MEMBER_OPTIONS` for containers, always `projectedRootEdges`, always `ELK_FORCE_ROOT_OPTIONS` for root); removed the radial `ROUTING_SKIPPED_LAYOUT_MODE`/`isRoutingSkippedLayout` guard so routing is unconditional when `edgeRouting` is on.
- **Kept**: force pipeline (elk force seed + d3 refinement) byte-for-byte unchanged; `ELK_FORCE_ROOT_OPTIONS`, `ELK_GROUP_MEMBER_OPTIONS`, `ELK_DIRECTION` (folder-group members still use elk's `layered` algorithm internally).
- **Persistence**: dropped `layoutMode` parsing. `PERSISTED_SHAPE_VERSION` intentionally NOT bumped — old `layered`/`radial` values fall back to force via the per-field parser (matches the codebase's established no-bump convention; deviation from ticket's "bump" wording, reviewer-approved).
- **Docs**: updated `docs-internal/architecture-map.md` and `docs-internal/specs/graph/arrows.md`.
- **Tickets**: closed this ticket; superseded/closed two now-moot tickets (per-doc layoutMode override; re-enable radial routing via web-worker).
