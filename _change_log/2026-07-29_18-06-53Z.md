Owner decided DELETE over building toggles: neither field could be changed by any user (no settings row, no in-graph control, no write-plan case).

- Folder grouping is unconditional; `deriveFolderGroups(nodes)` lost its boolean param and the flag stopped travelling through FlowGraph/FlowSnapshot/decideLayout.
- Only BFS-walked links become edges; `EdgeVisibility` (mode switch + unreachable induced-subgraph sweep) is now `EdgeCounts`, which only attaches provider link counts.
- Persisted keys removed. Stale values in an existing `data.json` fall back to spec defaults — clean break, plugin unpublished. Worth a release-note line.
- E2E routing fixtures now get their sibling chords from outgoing depth 2 (real walked links) instead of flipping a visibility mode; `harness.setEdgeVisibility()` is gone.
