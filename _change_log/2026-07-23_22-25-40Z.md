Global `nodeExclusion` setting ({enabled, patterns}) on PluginData (v1 additive, defensive parse). Pure `PathExclusionMatcher` (engine, import-guarded): each entry is a raw JS regex, case-sensitive, unanchored test against the full vault-relative path incl. extension — `rel/` matches anywhere, `^rel/` anchors; invalid patterns silently skipped; disabled/empty is a no-op. Applied at VicinityTraversal BFS neighbor discovery (before isNodeBearing) so excluded neighbors are never enqueued/expanded/metadata-fetched (perf win); active/central + pinned roots are exempt. Distinct rejected paths counted onto VicinityGraph.excludedNodeCount, surfaced via ControlsModel to a toolbar pill (shown only when enabled AND count>0) plus a settings-tab patterns textarea. Gates: npm test 713 passed, tsc strict clean, build ok.
